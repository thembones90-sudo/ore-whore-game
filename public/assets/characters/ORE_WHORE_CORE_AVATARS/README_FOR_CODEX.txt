ORE WHORE — CORE DIALOGUE AVATAR PACK
=======================================

STATUS
------
Canonical basic dialogue avatar states for the three protagonists: PEON, SHADEZ, and SYSTEM.

AVATAR DOCTRINE
---------------
- 1024 x 1024 PNG.
- Circular avatar composition / battered metal circular frame.
- No scenic background outside the circle.
- Alternate states are expressions of the SAME canonical character, not redesigns.
- Keep character identity, equipment, framing, proportions, and overall visual language consistent with the DEFAULT state.
- Do not casually regenerate or reinterpret these assets.

PEON
----
peon-default.png
  Neutral/default Peon. Use for ordinary dialogue, curiosity, listening, and baseline reactions.
  Typical read: “Boss… what this?” / “Boss… ore?”

peon-proud.png
  Smug, self-satisfied Peon. Use when he believes he has solved something, is impressed with himself, or reaches a catastrophically confident conclusion.
  Typical beats: “ME PRIEST.” / “Me have two hands.” / “ME RICH.” / “ME STRONG.”

peon-scared.png
  Alarmed / frightened Peon. Use for genuine danger, supernatural events, things moving on their own, hostile systems, bombs, wormholes, and moments where Peon finally understands that something is wrong.
  Typical beats: SHODAN, Broken Radio, Little Red Dress, Death’s scythe, Nuclear Gandhi, wormhole opening.

peon-angry.png
  Mundane offended / irritated Peon. NOT Berserk. No supernatural transformation or glowing eyes. Use when he blames shamans, rogues, ores, eggs, locks, bones, or reality itself for inconveniencing him.
  Typical beats: “STUPID SHAMAN.” / “ME HATE ROGUE.” / “Stupid ore.” / “Rude bone.”

SHADEZ
------
shadez-default.png
  Neutral/default Foreman Shadez. Controlled, intimidating, dry, and composed. Use for most ordinary Foreman dialogue.

shadez-angry.png
  Controlled fury. Same Shadez design, with more intense/narrowed eyes and a stronger forward threat. Use when Peon has pushed him past ordinary irritation.
  Typical beats: “IT IS NOT A ROGUE.” / “Absolutely not.” / “Put the pickaxe down.”

shadez-stunned.png
  Speechless / momentarily disarmed Shadez. Extremely restrained reaction. Use when Peon or SYSTEM says/does something so absurd that Shadez briefly has no answer.
  Typical beats: awkward silences, taser contradiction, Smiling Bomb realization, temporal-loop confusion.

shadez-somber.png
  Serious / mournful Shadez. Dimmer, lowered eyes and heavier posture. Use only when the joke stops and the scene carries actual emotional weight.
  Typical beats: Half of a Mask, Grain Shipment, Broken N7 Plate, Insignia of the Horde, The Oldest of Friends memorial.

SYSTEM
------
system-default.png
  Neutral/default SYSTEM. Stable green CRT face and ordinary telemetry. Clinical, dry, observant.

system-panic.png
  Alarm / panic SYSTEM. Face is expressed visually through widened CRT eyes and frantic waveform activity. No explanatory sentences on the screen.
  Typical beats: “STOP BREAKING THE ECONOMY.” / “PUT IT DOWN.” / “THREE!” / bomb fuse.

system-deadpan.png
  Judging / exhausted SYSTEM. Narrow horizontal CRT eyes and nearly flat telemetry. Use when SYSTEM is silently processing Peon’s stupidity or delivering maximum electronic disappointment.
  Typical beats: Peon reaches an idiotic conclusion; long pauses; dry rejection.

system-glitch.png
  Compromised / corrupted SYSTEM. Same physical terminal, but the CRT face goes catastrophically haywire like a failing GPU: dense green phosphor corruption, multicolored pixel artifacts, horizontal tearing, fragmented eyes, chaotic noise. No explanatory sentences.
  Typical beats: SHODAN intrusion, hostile interface takeover, Nanosuit overload, severe anomaly/corruption.

IMPLEMENTATION NOTE
-------------------
These are the 12 BASIC dialogue portraits. Special/environmental states such as SPACE PEON or one-off aftermath portraits are separate from this pack and should not replace these defaults.
